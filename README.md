## Проекты документации

### 🟢 Шаблон документации для сервиса приёма вебхуков

Шаблон для знакомства нового разработчика с серверным сервисом приёма вебхуков. Включает минимальную реализацию на FastAPI, описание архитектуры и инструкции по эксплуатации и устранению неполадок.

**Для кого:** backend-разработчики уровня junior и middle, которые присоединяются к команде и хотят понять работу сервиса на вебхуках и порядок внесения изменений.

**Что демонстрирует:**

1. Структуру документации для нового участника команды.
2. Понятное объяснение технических решений.
3. Описание типичных задач серверной разработки:
   1. обработка запросов;
   2. предположения и ограничения, связанные с безопасностью;
   3. идемпотентность;
   4. диагностика и устранение неполадок.

🔗 [Шаблон документации для сервиса приёма вебхуков](https://github.com/igor-rosliakov-techwriter/webhook-receiver-onboarding-template)

### 🟢 Локальная среда разработки серверного приложения на Docker

Шаблон локальной среды разработки на Docker Compose, в котором документация помогает новым участникам команды запустить сервисы, разобраться в их устройстве и работать с ними каждый день.

В репозитории есть небольшой API-сервис на FastAPI, фоновый обработчик задач, PostgreSQL, Redis и документация: как устроена система, как её запустить, отладить и поддерживать локально.

**Для кого:** backend-разработчики и новые участники команды, которым нужно запустить многокомпонентное приложение на своём компьютере и понять, как оно работает.

**Что демонстрирует:**

1. Введение разработчика в локальную среду проекта.
2. Документирование работы с Docker и Docker Compose в серверной команде.
3. Объяснение взаимодействия компонентов:
   1. сохранение данных из API в базу данных;
   2. постановка фоновых задач из API в очередь;
   3. выполнение задач фоновым обработчиком.
4. Эксплуатационную документацию:
   1. проверки работоспособности;
   2. порядок отладки;
   3. типичные проблемы локальной разработки;
   4. инструкции для распространённых сбоев.

🔗 [Локальная среда разработки на Docker](https://github.com/igor-rosliakov-techwriter/dockerized-backend-dev-environment)
